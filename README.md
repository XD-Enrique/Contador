# Contador

Um aplicativo web simples de contador com interface moderna e persistência de dados.

## Descrição

Este projeto é um contador interativo que permite:
- **Incrementar** o valor clicando no botão "+"
- **Decrementar** o valor clicando no botão "-" (não vai abaixo de 0)
- **Resetar** o valor para 0 com o botão "RESET"
- **Persistir** os dados no navegador usando localStorage

## Tecnologias

- **HTML5** — estrutura semântica
- **CSS3** — layout responsivo com Flexbox
- **JavaScript** — lógica de contador e manipulação do DOM
- **localStorage** — armazenamento local de dados

## Como Usar

1. Abra o arquivo `index.html` no navegador
2. Use os botões para:
   - **+** para aumentar o contador
   - **-** para diminuir o contador (mínimo 0)
   - **RESET** para voltar a 0
